== Description ==

Wild Lemon is a warm editorial blogging theme built entirely on core blocks — query loops, post templates, pullquotes, and navigation. Newsreader carries the reading experience, Schibsted Grotesk handles the interface, and a single lemon accent ties it together. No plugin dependencies.

== Changelog ==

= 1.3 =
* Strengthen search and comment field outlines and include an accessibility statement describing supported features, testing, limitations, and support contacts.
* Improve mobile navigation, search forms, author cards, post navigation, and archive row spacing.
* Refine footer link columns with balanced responsive spacing, clear headings, consistent RSS styling, and accessible pointer and keyboard targets.
* Keep the labeled Search button and expand its field within the header row without moving page content. Respect reduced motion and retain native WordPress search interactions.
* Show native reading-time estimates beside the author on the featured homepage post and single posts in WordPress 6.9 and later, styled with the published screenshot's compact label and dot separator.
* Refine three editable editorial patterns using the existing theme typography, responsive spacing, and bundled imagery. Keep template-only pattern fragments out of the public inserter.
* Add three core-block patterns: A table for the season, A day in pictures, and A slower weekend, with bundled photographs and native expandable notes.
* Make older archive posts reachable with pagination while retaining the original homepage sections.
* Correct Query Loop offset totals, remove links to empty archive pages, and show an inline no-posts message in empty homepage sections.
* Keep archive titles readable with many categories and inside narrow pattern containers. Link post dates so untitled posts remain reachable.
* Restore page comments and classic multipage-post links, improve nested comment readability and mobile menu targets, and preserve empty-query pagination behavior on WordPress 6.7.
* Fix mobile overflow from classic image captions, audio players, and long previous/next titles. Verify the full official Theme Unit Test import on current and minimum WordPress/PHP versions, plus Firefox and WebKit.
* Allow wide patterns inside pages and posts, and contain long code, tables, words, and nested comments on small screens.
* Correct homepage and 404 links so they lead to the labeled destination on any site.
* Test with WordPress 7.1 and align theme metadata with the published features.

= 1.2 =
* Accessibility: meet the accessibility-ready requirements — WCAG AA color contrast across the palette (darker Stone Light, lighter footer text), visible focus styles on the 404 search field, and audited heading order, landmarks, labels, and skip link.
* Address theme review feedback: truthful style.css tags, block style variations for post terms, bundled asset licensing documented, author details corrected.

= 1.0.0 =
* Initial release.
